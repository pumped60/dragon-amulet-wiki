# Dragon Amulet Wiki

Every item, recipe, class, monster, boss, animal, shop and crafting station in Dragon Amulet, all linked, with search.
Read it here: **https://pumped60.github.io/dragon-amulet-wiki/**. Play the game at https://pumped60.github.io/dragon-amulet-play/.

On a phone, add it to your Home Screen (iPhone: Share, then Add to Home Screen; Android: Install app) and it becomes its own
app beside the game, and works offline. This repository is generated from the game's source by tools/make_wiki_app.py.
